Global constraints and architectural decisions. Updated at the end of each phase.

## Core Constraints

- **Monorepo:** Turborepo + pnpm. `apps/web/`, `packages/db/`, `packages/ui/`, `packages/eslint-config`, `packages/typescript-config`.
- **Routing:** `src/proxy.ts` (NOT `middleware.ts`) — a CI guardrail enforces this.
- **Auth:** Supabase cookie-based, enforced in proxy + RLS. No client-side Supabase. No per-navigation `auth()` in layouts.
- **Supabase clients:** Only via `apps/web/src/shared/lib/supabase.ts`.
- **Env vars:** Only via `apps/web/src/shared/lib/env.ts`.
- **DB client:** `import { getDb } from '@memory-palace/db'`. All Drizzle helpers from `@memory-palace/db`, never from `drizzle-orm` directly.
- **Server Actions:** Zod → `checkRateLimit` → Drizzle. Return `ActionResponse<T>`.
- **Exports:** Named only outside route files.
- **CSS:** Mobile-first. No `max-*:` breakpoints.
- **`cn`:** From `@memory-palace/ui` only.
- **Cross-feature imports:** Forbidden by `eslint-plugin-boundaries`. Cross-cutting code → `src/shared/`.

## Post-Phase 6-7 Conventions (ADR 8)

- **Route regexes:** `PALACE_PAGE_RE` and `ROOM_ROUTE_RE` live in `shared/lib/routes.ts` — import from there, never redefine locally.
- **Canvas custom events:** All `window.dispatchEvent` / `window.addEventListener` canvas event names use `CANVAS_EVENTS.*` from `shared/lib/canvasEvents.ts` — never bare string literals.

## Phase 8C/8D/8E Architectural Decisions

- **Root `/` conflict resolved:** `(dashboard)/page.tsx` deleted. `/` is now the marketing landing page. Authenticated users hitting `/` are redirected to `/palaces` in `proxy.ts`. Post-login redirects in `signIn.ts` and `signUp.ts` point to `/palaces`.
- **`(marketing)` route group:** Public pages (`/`, `/about`, `/join`) live in `app/(marketing)/`. They use their own layout shell (MarketingNav + MarketingFooter) and override `robots: { index: true }`.
- **CSP via proxy nonce, not next.config headers:** `generateNonce()` called in `proxy.ts`; nonce forwarded to RSC via `x-nonce` request header; read in root `layout.tsx` via `headers()`. Static CSP in `next.config` is incompatible with per-request nonces.
- **Onboarding wizard step state in URL params:** `/join?step=N` — survives page refresh, enables browser back/forward. Accumulated data (palaceId, roomId) in `useReducer` local state.
- **`createWizardSetup` creates palace + default room atomically:** The wizard's node step needs a `roomId`; the palace action inserts both in one transaction and returns both IDs.
- **Magic-byte MIME detection in `/api/upload`:** No external package (`file-type` etc.) — 12-byte prefix check in plain TS. SVG rejected server-side due to XSS risk.
- **`useConfetti` dynamically imports `canvas-confetti`:** Never in the initial bundle. Used in `StepComplete` and available for Phase 9 gamification.

## Phase 7 Architectural Decisions (complete)

- `LazyMotion` + `domAnimation` at root (`MotionProvider`); `m` component at call sites. `domMax` deferred to Phase 8.
- Three-layer reduced-motion: `reducedMotion="user"` on `LazyMotion` + `useReducedMotion()` in components + Tailwind `motion-reduce:` CSS fallback.
- React Flow node exit via `isExiting` local state pattern (200ms delay before calling `onDeleteNode`) — `AnimatePresence` exit is not compatible with React Flow's node lifecycle.
- Page transitions: `AnimatePresence mode="wait" initial={false}`, keyed on `usePathname()` in dashboard layout.
- `canvas-confetti` dynamically imported in `useConfetti` hook — never in the server or initial client bundle.
- Simple hover/press interactions via Tailwind only (`hover:-translate-y-0.5`, `active:scale-95`) — no framer-motion.
